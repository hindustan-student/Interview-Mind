Features

Every feature is built end-to-end — from the AI scoring engine to the neon-animated UI — to deliver a world-class interview preparation experience.

🧠

AI Mock Interview

Simulates a real interviewer with role-specific questions, difficulty levels, and instant STAR-method feedback on every answer.

📄

Resume ATS Analyzer

Upload PDF / DOCX / TXT resume and get an instant ATS score with keyword coverage, missing sections, and tailored recommendations.

📚

Curated Question Bank

Hand-curated questions across behavioral, technical, system design, coding, HR, and situational categories — modeled on top tech interview prep.

📈

Performance Dashboard

Track every mock interview, see your score trends, identify weak categories, and watch your confidence grow over time.

🔒

Secure Auth

Flask-Login sessions, Werkzeug password hashing (PBKDF2-SHA256), CSRF protection, and per-session interview history.

⚡

Real-Time Feedback

After every answer: score, strengths, improvements, STAR breakdown, keyword match, and confidence proxy — all computed locally, no API needed.

Architecture Highlights

InterviewMind follows a clean, layered architecture so that academic reviewers can audit each layer independently:

  • ✓ Application Factory Pattern — modular Flask app creation across dev/test/prod configs.
  • ✓ Blueprint-Based Routing — main, auth, interview, resume, questions, dashboard, API.
  • ✓ Service Layer — AI interview engine, resume analyzer, question bank are pure-Python and unit-testable.
  • ✓ SQLAlchemy ORM Models — User, InterviewSession, Answer, ResumeReport, QuestionBankItem.
  • ✓ Custom Canvas Particle Engine — neon background with mouse interactivity and DPR-aware rendering.
  • ✓ Accessibility-Conscious — respects prefers-reduced-motion, keyboard-navigable forms, ARIA labels.
  • ✓ Pytest Test Suite — covers routes, AI engine, resume analyzer.
